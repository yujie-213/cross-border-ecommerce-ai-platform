## 完成功能与实现

- 根目录Start-Platform.cmd/Stop-Platform.cmd：双击启动API、独立Worker、生产前端服务并打开浏览器；无900秒运行期限，固定本机入口。三个子进程放入当前Windows Job，正常停止/监督进程突然结束只清理自己；文件锁防重复启动，端口被其他服务占用时拒绝启动，不按端口杀进程。
- Initialize-Platform.cmd/Reset-Admin.cmd：显式隔离库前向迁移/首次单admin初始化和本机密码重置。指定密码已通过隐藏输入在本机设置，源码/README/Git/配置和公开证据均不含真实密码或哈希。DB只存随机盐scrypt派生值；私有签名密钥独立随机并持久保存。
- 默认8小时会话，JWT/数据库/Cookie同截止，保留HttpOnly/SameSite Strict/CSRF/服务端权限与撤销；本地loopback HTTP Cookie例外明确限定，HTTPS仍Secure。密码重置增加身份revision并撤销原会话，不重置业务历史。失败计数/短暂锁定跨服务重启保留。
- 普通账号密码登录页与当前会话恢复，不再复制Token；开发测试装配仍保留原Bearer入口。401清失效Cookie并回登录，错误有提示、无跳转循环。超级管理员拥有现有平台动作，仍不能绕过ERP来源、自有采购范围、报价/MOQ/整箱与人工认知确认。
