## 配置与调用边界

沿用 `bootstrap.settings.load_settings` 的本机忽略 `.env` 和环境变量优先级，密钥采用 SecretStr，仅 HTTP 适配器运行时读取，不写入命令行、日志、审计或 Git。环境变量示例见根目录 `.env.example`。本轮只核对到 `COMMERCE_MODEL_API_KEY` 变量存在且非空，未显示其值；本地已有 `COMMERCE_MODEL_PROVIDER` 未通过新枚举校验，未擅自修改 `.env`。运行本轮离线验证时显式覆盖 provider=mock、network=false。未来经授权连通时须明确设 provider=deepseek，官方 URL/模型按示例核对。

| 配置 | 默认与约束 |
|---|---|
| COMMERCE_MODEL_PROVIDER | mock；真实适配只接受 deepseek（大小写归一；deepseek_official/deepseek-official 同义） |
| COMMERCE_MODEL_BASE_URL | https://api.deepseek.com；不接受自定义主机、明文 HTTP、路径、查询或重定向 |
| COMMERCE_MODEL_NAME | deepseek-flash；未知/旧模型名拒绝，未静默映射旧名 |
| COMMERCE_MODEL_API_KEY | 空；密钥非空不代表付费授权 |
| COMMERCE_MODEL_NETWORK_ENABLED | false；还须独立授权对象，开关本身不授权调用 |
| COMMERCE_MODEL_TIMEOUT_SECONDS | 15，0 < timeout ≤ 30 秒；受原任务及本 attempt deadline 缩短 |
| COMMERCE_MODEL_MAX_OUTPUT_TOKENS | 512，范围32—1024；真实连通入口强制最多128 |
| COMMERCE_MODEL_MAX_CONCURRENT | 1，范围1—4；受控装配使用 |

A01 公共入口仍是 AI 详设§9.1 的 ModelRequest 0.2，不接收自由 messages/parameters/deadlineRef/toolSpecs 别名。当前实现仅 S01 解释用途，query 形状可校验但执行返回 UNSUPPORTED_QUERY，无工具、流式或缓存。只注册当前一个工程 Prompt/Context/四数组 Schema 和参数版本，未知引用拒绝；未来真实 Context 准入和用途语义验证归 S01/C-04。

S01 调用方先通过同一个 `ExecutionContext.budget.reserve` 预留，`reserve_request` 构造精确请求；网关再次核对当前 G01/O01 task/lease/plan/主体/policy/allowance/deadline 及受控 Context 的 participant/snapshot。A01 生成 ProviderRequest payload/control 与服务器摘要。Prompt/Context 仅承载最小合成事实、引用和限制；不传身份/任务控制、源明细或隐藏推理。输出经有界四数组完整本地 Schema 校验；只返回解释数据，无法取得 B01/B02 的可写对象或修改其计算。

O01 预算行串行核验 send admission，MODEL_SENT 审计和 SENT 同短事务提交；跨网关/进程同任务并发槽共享该预算，重复 attempt 不重发，同 logicalCall 的未决 attempt 阻止新发送。UNKNOWN 阻止该任务后续新收费调用。每个网关另有进程内 semaphore，响应/超时后台 IO 尚未结束时不提前释放；这不是跨所有任务/所有进程的供应商全局配额设施。未建设第二调度器或预算表。网络始终在数据库事务/锁外，每次核账独立连接。

没有自动重试；已知拒答/失败如需重试，由调用者明确创建同 logicalCall 的新 attempt，仍扣原任务次数/token/费用和原期限。RESERVED 且可证明未发送时才释放；SENT/UNKNOWN 不退款。重启不重置预算，原已结算但未持久化的解释返回 RESULT_UNAVAILABLE，不从 usage 编造模型内容。取消/超期/失 lease 后停止等待并禁止返回解释；后台迟到 usage 仅可核账。进程被终止时保留 SENT/UNKNOWN；后续须按原 attempt 核对。

Mock 返回 TEST 实际金额，经原 TaskBudgetHandle.settle/G02 唯一 usage 事实幂等核账；超过预留仍全额记录并拒绝输出。DeepSeek 响应只有已知 token 时，在 G02 MODEL_RESULT 技术事实中保留 token、finishReason、摘要化 request ID、版本及 actualCost=null；O01 全部预留继续占额，返回 USAGE_UNKNOWN，不拿估价代替账单。费用最终核对仍使用原 attempt 的受控 settle 端口；本轮没有真实账单核对器或伪造 usageRef。

G02 保存 task/plan/participant/snapshot/logicalCall/attempt/allowance/trace、Prompt/Context/Schema/参数引用与内容摘要、配置与已核对实际模型、耗时和技术状态。不保存请求/响应全文、API Key 或 Authorization。远端异常文本完全丢弃，未知模型只记录 digest。审计发送失败不发网络，核账/必需审计失败不返回成功；已发送未知继续占额。

## 官方接口依据与保留条件

2026-11-12 只读核对官方文档：

- 模型/价格：`https://api-docs.deepseek.com/quick_start/pricing`。当前 `deepseek-flash` 对应 DeepSeek-V4.1-Flash-1017；别名由供应商维护，不承诺不可变远端 revision，响应 model 与配置不同会失败关闭。
- Chat Completion：`https://api-docs.deepseek.com/api/create-chat-completion`。固定 POST `/chat/completions`，`thinking={type:disabled}`、`response_format={type:json_object}`、`stream=false`、显式 max_tokens、无 tools。JSON Output 保证与本地完整 Schema 校验分层；并未声称原生 strict JSON Schema。
- JSON Output：`https://api-docs.deepseek.com/guides/json_mode`。Prompt 明确要求 JSON 并给 Schema；空白、缺字段、错类型、拒答、length 截断、非法工具结果均拒绝。

官方 Flash 峰值 cache-miss 输入 $0.30/百万 token、输出 $1.20/百万 token，仅作带日期的保守发送额度检查，供应商缓存不减本地预留。输入上界用 UTF-8 字节数加4096 framing allowance，输出最多128；max cost 须覆盖计算上界。价格会变化，**真实执行前必须重新核实并评审该上界**；本地费用约束不能代替供应商账单/账户消费硬限额。自动价格发现/模型替换未实现。真实 TLS、能力、别名稳定性、usage/cache 维度及计价合同本轮均未实测，不能以离线 HTTP fixture 代替。
