# 设计说明

序衡采用浅灰作业底、白色数据面和深青操作色，以对象、限制、证据、操作组织页面。SAP启发稳定框架，Airtable启发主次层级，Shopify启发浅色交易场景；不沿用品牌色、巨型标题或营销装饰。

工作台聚焦阻断与待复核；列表服务连续扫描与筛选；详情用一幅逐日余额图及等价数据表解释补货时序，保留单位、库存分桶、可售日、MOQ、质量和证据。未知金额与交期不编造。

原型决定功能与操作顺序，DESIGN.md决定视觉表达。默认只读；审批需显式进入演示，生成、确认、提交、独立审批分开，批准不执行。改数量使旧批准失效；未评价的新数量不能提交。质量缺失、库存过期和重复供给持续阻断。

已实现四页导航、筛选、固定情景比较、证据反馈、模拟分析与审批。全部数据、身份、期限和日志为会话演示；ERP、权威计算、模型、服务端权限、持久化和执行均未实现。浏览器验证不能替代企业验收。

请负责人确认试点SKU/仓与单位、库存与需求口径、供给可售日、数据时效及质量矩阵、审批角色/金额/期限，以及首期只读范围和页面密度。确认前不进入正式前端开发。
