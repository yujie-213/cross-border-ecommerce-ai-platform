## 03 核心差异与保持不变的内容

| 主题 | 修改前 | 修改后 |
|---|---|---|
| 基座验收终点 | 代码包、部署与流程可推导，但没有首批通过判据 | MC01—MC12 可验收跨进程持久闭环、回滚、重启、租约、权限与证据；工程模拟与真实系统资格分开 |
| 审批提交提交者 | “发起用例”与“共享事务” | 精确到 C01 SubmitForApprovalUseCase；一条 Session、一份短事务、一次 commit/rollback；C02/G02 只能写自己数据并 flush |
| 无环协作 | 两个完整服务可能互相注入 | C01 提交→C02 独立提交命令；C02 决策→C01 独立只读视图；消费方端口、组合根装配 |
| 即席查询预算 | 概述限额，未定义非任务路径的状态归属 | A03 的技术运行记录承担预留/结算与周期/并发控制；G02 记录成本事实；不借 O01 假任务或新预算平台解决 |
| 外部执行依据 | 快照/批准加笼统前置核验 | 获批依据与当前来源观察分开；必须证明写入点的原子条件/不变量；来源并发冲突显式失败或 UNKNOWN |
| 任务恢复层 | 通用 RECOVERY_REQUIRED 状态夹带源核对条件 | 通用投递状态精简，所有者按已有业务状态恢复；UNKNOWN、回执与同键重发门槛仍归 C03 |
| 目录与约束维护 | 全量目录树；约束多处重复 | 首批/后续公共/未来场景分列；规则索引与细则引用统一维护 |

保留原有完整业务范围、公共模块编号和数据权威；O01 仍经 ScenarioHandler，B02 仍单向复用 B01，A01 仍不负责业务降级；Milvus/Neo4j 仍为候选，未增加 Redis、MQ、微服务或独立治理/恢复平台。MC 仅为 M1 的工程交付切片，不调整 M0—M4。

## 04 主要剩余验证事项

| 关联项 | 仍需取得的事实或决策 | 不满足时的边界 |
|---|---|---|
| V01/V12、H01/H07 | 冻结依赖版本、驱动与迁移、S02 模拟字段/期望、运行配置与 MC 验收脚本 | 本轮不初始化工程；模拟通过不承诺真实接口/全场景已完成 |
| H02、V01 | 同连接/Session 的事务绑定、内层无 commit、所有注入点回滚与提交结果不明后的原命令查询 | 实现不满足原子性则不得启用提交审批；不能用两个服务分别提交替代 |
| V05、H03 | 即席请求/周期额度、期限、并发与未知用量；正式/即席额度分配；是否要求跨入口共享总额硬上限 | 相关收费控制未配置/未验证即关闭模型收费路径，不以两个独立计数冒充共享总额 |
| V06、H04 | ERP/CRM 当前状态读字段、权威版本、条件执行覆盖、多对象不变量、幂等期限及回执 | 无可靠保证则不启用自动动作，只保留建议/人工流程 |
| V07/V08、H02/H04 | 独立审批岗位、代理/撤销竞态、身份签发与 Worker 恢复权限 | 不假设已存在企业 SSO；在途请求不能被本地锁保证撤回 |
| V15、H05 | 租约/重投/终态复用及未决 C03 + DEAD 工作项的人工核对责任、保留与备份 | 工作项结束不抹去外部 UNKNOWN；不静默丢失未决执行 |

其他 V01—V15 仍以概要正文第 19 节为准。此处只总结本次修改直接相关的验证缺口，不新增业务需求。
