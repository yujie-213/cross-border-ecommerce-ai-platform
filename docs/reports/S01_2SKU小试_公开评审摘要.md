# S01 方案 C：2 SKU 小试准备评审摘要

负责人已批准方案C的顺序：独立范围与2SKU能力小试，随后8SKU完整场景及S01联调、整体验收，稳定后再考虑扩容。当前仅第一阶段准备，**有业务副作用的精确执行清单仍须批准**。

本次计划核查正式API写入/独立回读、真实ID关联、报价约束、销售及库存副作用、采购/部分收货、余额与流水、过滤/分页/幂等、数据归属登记。拟定33次业务变更、76次业务回读，仍受40/80硬上限约束；完整字段、业务记录和环境检查材料留在本地，不在此公开摘要中。

小试设计一条可形成候选的路径和一条无需补货的路径。这里描述的是待执行目标，**不是ERP实测结果**。范围独立性、关键读取能力、教学凭证与出入库副作用必须先明确；任何503/超时、身份漂移、关联不完整或对账失败都阻断，不以创建成功替代业务验收。

统一范围规则见[自建数据集范围契约](../contracts/s01/owned-dataset-scope.md)。只有本项目创建、登记且独立回读/关联验证通过的真实ERP成员才可进入监控，所有查询、分析和统计采用同一范围版本及G01权限。清单可配置，不以名称、前缀或固定SKU数量当作权限边界；它不能替代ERP侧隔离。
