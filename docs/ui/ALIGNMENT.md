## 已实现的本地交互

四页导航、搜索/店铺/仓/状态组合筛选、排序、空态与恢复、固定供需图/数据表、证据卡与拒绝访问反馈、当前筛选CSV导出；固定SKU分析受理/发布/取消/降级/暂停反馈；显式开启协作演示、创建建议/确认/提交/角色切换/批准/拒绝/版本失效/撤销/模拟过期；重置与刷新清空。

## 占位演示

全部店铺/仓/SKU、库存/供给、候选、报告、快照/证据ID、供应商、身份、审批期限、时效/质量阈值、任务执行耗时、操作日志与UNKNOWN核对结果。CB-1001使用已有需求演示数字；其余为异常结构样例。已有示例不构成新需求冻结。

## 尚未实现

企业系统/数据库/API、真正的B01/B02与模型、快照冻结/证据解析、租户与行列级权限、浏览器认证、任意SKU/时点/数量重算、跨域联合分析、持久审批/审计、事务幂等/并发冲突、真实有效期与权限撤销、后台任务与恢复、ERP采购草稿执行及业务结果跟踪、正式可访问性审计/真实用户可用性测试。无批量审批、分页后台、通知推送、列配置或完整多场景门户。

这些限制在原型顶栏、入口弹窗、“原型范围与待确认”及相关详情中可见。未实现按钮禁用并给原因；存在的交互必须给反馈。正式前端开发需负责人确认产品流程、视觉规范与关键业务口径后另行授权。
