# B V1.0 本地交互原型

双击 `index.html`，用 Edge 或 Chrome 打开即可，不需登录或启动中台。整个目录一起保留。页面持续标注“交互原型 · 模拟数据”，不连接真实 API、ERP 或模型，刷新恢复初始样例。

推荐体验：

1. 平台首页 → 售后工作台（默认ERP已有工单模拟）→ 上衣尺码与描述不符。直接查看已核商品、业务事实及AI处理建议，生成模拟回复草稿、人工编辑采纳、查看处理历史。
2. 工作台 → 待补证 → 两件商品的订单。仅本订单商品可选，首次确认不用理由；已关联商品的“关联依据与人工纠正”中改选另一商品才必填原因，并保留原关联。缺订单的记录提示补充凭证，没有随意商品候选。
3. 工作台 → 商品评价与客户反馈 → 分析该商品体验。商品评价关联商品但订单未知；独立订单反馈如有多商品歧义则核实。评价全部为中台模拟，不宣称已接ERP。
4. 分析优先看本期30%、上期2.5%、上升27.5个百分点，AI反馈总结、已核事实／可能原因、下一步。打开原文、相关教学案件及退货证据，再创建调查。统计口径与规则在高级详情，定义不变。
5. 质量风险 → 人工确认精确范围 → 补货展示。单品改量／批量筛选后打开证据、进入风险详情并返回，原上下文保留，参考补货量始终100。关闭、撤销、失效及版本可追溯。
6. 顶栏“教学与异常演示”独立提供内部教学案件创建、USB尺码冲突、安全升级、数据不足、无政策、失败、权限和历史版等测试状态；不是正常业务步骤。

全部操作只在本次页面内存，不发送客户消息，不退款、确认缺陷或执行采购。ERP已知与未知及证据见 [产品说明§8](../../docs/ui/B_AFTER_SALES_PRODUCT.md)。当前仍等待负责人一次方向确认，未开发正式Vue。
