# B V1.0 本地交互原型

双击 `index.html`，用 Edge 或 Chrome 打开即可，不需要登录、安装依赖或启动中台。CSS、JavaScript 均在同一目录，整个目录一起保留。页面顶部持续显示“交互原型 · 模拟数据”，不连接真实 API、ERP 或模型。

推荐体验：

1. 平台首页 → 售后工作台 → 打开上衣案件，明确选择目标行、获取模拟证据、生成模拟建议、编辑并采纳；查看历史，追加消息体验旧草稿失效。
2. 切换体验与退货分析，点击 `12/40` 及分母，查看对应事件、发货和原文；切换未成熟状态体验 UNKNOWN。
3. 记录调查 → 质量风险 → 填写理由并明确确认店仓 → 补货展示。在单品编辑数量，再切批量、打开证据、进入质量详情并返回，核对筛选、视图和数量保留。
4. 用各页“原型状态演示”选择无政策、安全升级、失败、空队列、撤销、到期、错店与正常 ERP 模式等负例。

所有编辑仅保留于当前页面会话，刷新或点击“重置演示”恢复合成样例。页面不持久保存客户信息。演示审核、风险确认均非真实业务动作；补货参考量固定 100，采购提交未接入。

原型供负责人进行一次整体操作方向确认，不代表三条业务链、ERP、真实模型或采购联动已经验收。正式 Vue 页面和剩余业务实现按下一次连续授权接续。
