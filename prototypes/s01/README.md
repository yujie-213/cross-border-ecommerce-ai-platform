# S01 独立交互原型

双击 `index.html` 即可离线预览，无安装、无构建、无远程资源、无业务接口。全部状态在页面内存，刷新重置。不加载正式业务代码，不写入ERP。

也可从本目录运行 `python -m http.server 8765 --bind 127.0.0.1`，在浏览器访问 http://127.0.0.1:8765 。这是可选本地预览，不是部署。

## 建议审查路径

1. 工作台 → 数据/质量阻断 → 查看异常原因；列表搜索SKU、切换店铺/仓/状态，检查空态恢复。
2. CB-1001详情 → 查看55/90/15/20样例、逐日表、D8延期情景与D6短缺、证据无权访问反馈。
3. 顶栏开启审批流程演示 → 选择20件候选 → 生成草稿 → 勾选确认 → 明确提交 → 切换“审批·周宁” → 批准或带理由拒绝。
4. 批准后执行始终禁用；切回采购，将20改30，新版本清除旧批准适用性；30未经评价，不能确认提交。可查看原键UNKNOWN核对预览。
5. 新建分析可选正常/解释失败/B02失败/质量阻断/YIELD；运行中可取消。输出仅固定演示，不计算真实候选。

入口文件负责产品行为；视觉实现使用 styles.css，视觉规则在根目录 DESIGN.md。详细依据、占位与未实现项见 docs/ui/PRODUCT_SPEC.md、ALIGNMENT.md、DESIGN_NOTE.md。

## 本地验证

`node prototypes/s01/check.cjs` 从项目根目录运行，使用本机现有 Playwright 与 Edge。可通过 `PLAYWRIGHT_MODULE`（包 package.json 的绝对路径）和 `BROWSER_EXECUTABLE` 覆盖现有浏览器位置，无安装动作。结果与截图写入 evidence/。这是前端模拟交互验证；ERP/模型/MC/S01业务验收均 NOT_RUN。
