## 合成原则

以“对象、限制、证据、操作”的业务阅读顺序作为统一骨架。颜色只表达交互与状态；SKU/仓/单位/时点常驻；表格承载批量扫描，详情用逐日数据解释补货风险。品牌参考解决视觉组织，冻结需求决定功能与权限，两者不互相代替。

项目没有复用任一品牌的完整 token 表。新配色、字号、导航与数据密度由当前中文企业作业场景独立确定，具体见根目录 DESIGN.md。原型审查依据与缺口见 ALIGNMENT.md。
