## 用户与信息结构

采购：判断对象、时间、数量、依据和风险。审批人：审核冻结版本与证据，独立决定。数据/质量负责人：补证、调查与修复来源。审计用户：追溯报告、参数、审批和回执；真实字段权限待冻结。

导航仅“工作台 / 补货建议 / 人工审批”。建议详情从列表进入，避免重复菜单；证据用模态定位卡，返回时保留当前筛选。原型用 URL hash 导航，筛选在会话内保留；刷新全部恢复，非持久业务状态。

## 只读路径与协作路径

默认：选择固定店铺/仓/SKU/时点 → 模拟运行 → 本次任务状态与模拟产物标识。工作台与列表始终标为历史固定 report-v1；成功任务有独立会话任务/产物ID，入口仅“对照历史固定报告”，未实现本次产物详情页。仅基线、阻断、取消、运行中与暂停均无本次报告ID或查看入口。详情日期预览不作为新任务输入；成功反馈明确复用原计划样例。运行、受理不等于发布；YIELD 不发布。本轮只测试前端状态反馈，没有真实 task、plan 或预算。

协作：用户明确点击“开启审批流程演示” → CB-1001 选择候选 → 生成建议草稿 DRAFT → 勾选复核确认，保存 CONFIRMED（无审批） → 明确提交，建议 SUBMITTED、审批 PENDING → 独立“周宁”批准/拒绝。发起人“林予”不能审批。模拟身份切换仅用于审查，不是认证设计。

批准显示 APPROVED 并同时校验建议版本及情景修订，执行入口禁用，不创建 C03 工作项。修改 20→30 件使建议变为新版本 DRAFT，旧批准不再适用；30 件未获 B01 评价，禁止继续确认/提交。可将人工假设改回固定 20 件继续演示，不伪造任意参数重算。

## 异常与恢复

| 异常 | 展示与可做事项 | 禁止行为 |
|---|---|---|
| 质量调查 | 12/100 成熟签收群组的投诉占比；调查责任与证据 | 称为缺陷率、直接转采购 |
| 质量缺失、库存过期、重复供给 | 持续阻断提示、缺项、责任方；补证后需重分析 | 缺失按0/安全、浏览器覆盖源事实 |
| 可售日均延至D8 | 固定对比显示D6首次短缺；已有建议转SUPERSEDED，原确认失效；审批保留历史决策并注明已失效，不能继续批准。切回原计划不恢复旧确认/审批，须选择候选建新版本 | 静默切回情景、复用旧批准、把延期预览当已发布报告 |
| 解释不可用 | 已有规则报告保留并注明限制 | 用模型失败推断质量安全 |
| B02 不可用 | 仅基线，不生成候选 | 伪造预测、补货量 |
| 证据无权/不可用 | 明确无法核实、联系数据负责人 | 暴露源明细、继续冒称依据完整 |
| 拒绝 | 必填理由，回到复核路径，记录意见 | 无理由通过、把审校当业务批准 |
| 批准过期/撤销/新版本 | 旧批准失效，需要当前版本重新确认/提交 | 复用旧批准直接执行 |
| 回执 UNKNOWN | 仅演示原 executionKey 核对，仍未知转人工 | 换键重发、把202或重启当成功/失败 |

## 数据与交互边界

完整数字样例仅 CB-1001，来自需求 AC-02/03 的演示。其他 SKU 为结构/异常样例，未给明细显示未提供，不编造财务与交期。所有来源 IDs、供应商、身份、阈值和日期为模拟。金额/币种未知，不计算货值。

图表仅绘制 demo-data.js 已存每日余额，没有库存/金额公式。基线包含原未收供给20件，不包含候选采购；候选行另加入采购20件。日末净额负值表示累计未满足需求，不能当作实物负库存。原计划为原供给D4、候选D6可售，首次短缺D8（基线）；延期样例两者D8可售，基线和候选均D6首次短缺。目标90/缺口15始终标为历史指标，延期未重新评价，不用D8供给反推新的目标缺口。D1=2026-11-11，当日供给先计入再扣新增需求；是否采用此日粒度及缓冲末日计法仍需业务冻结。预留需求不重复作为新增需求扣减，到港不等于可售。

情景修订只作用于CB-1001。工作台/列表提示历史报告与情景差异、审批失效；其他SKU不继承延期警告或可售日。查看来源报告只导航，不修改情景。建议来源统一为task-demo-1111 / plan-v1 / report-v1；建议版本与报告版本分别展示。源历史报告不改写，新版本不继承旧审批；操作记录保留失效及旧决策说明。本原型只保留当前建议/审批对象，不是完整版本历史查询。

来源 manifest 归 D03；证据定位归 D04；报告/计划归 O01；前端仅以引用关联。真正的鉴权、幂等、事务、预算、可靠取消、审计和恢复均未实现。

## 负责人确认清单

1. 试点租户/店铺/仓/SKU/单位；库存互斥分桶、镜像与供给去重口径。
2. 日新增需求、窗口/缓冲、可售日与交期依据；MOQ/倍数；逐日评价粒度。
3. 数据域时效、质量 required/optional、投诉调查阈值与安全降级矩阵。
4. 是否认可只读首期；何时另开 C01/C02/C03；建议人工调整与再评价规则。
5. 独立审批岗位/代理、金额/币种/阈值、有效期、撤销与来源变化策略。
6. 当前页面层级、中文密度与桌面/窄屏取舍；真实样例与验收人。
