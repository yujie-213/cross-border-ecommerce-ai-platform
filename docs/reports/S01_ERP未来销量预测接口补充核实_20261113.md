过程保留真实失败：首次私有调查工具误要求 Listing 存在 product_id/store_id，而该资源实际返回 sku/store_name/listing_id，预检停止；按真实契约修正后继续，未影响应用。后续重复读取同一个已验证自建店铺时连续两次 503；再次读取身份也连续两次 503，均已停止该项重试。之后只补查尚缺的马克杯精确查询及另一汇总维度，使用本次已成功验证的同一账号/店铺关系；两项均先 503、退避一次后 200。503 不改成成功，先前成功回执也不冒充第二次成功；接口整体稳定性仍有限制。

本轮合计 25 次网络尝试：4 次认证、18 次 GET、3 次明确只读的汇总 POST；业务读取 21 次，其中 15 个 200、6 个 503。低频请求，仅对临时只读失败作一次退避重试。认证敏感响应不落盘；其余原始响应仅在 Git 忽略的 `data/private/s01-forecast-survey-20261113/`，没有查询其他 SKU 或无筛选读取共享业务库。

## 是否需要额外参数或其他接口

遍历本地 OpenAPI 的全部 178 路径、252 操作并解析响应 Schema 引用；在当前完整契约内，没有找到其他独立未来销量预测、可指定未来时间范围的需求预测、或未来逐日需求曲线接口。关键词匹配到的备货单详情 `predicted_*` 是预计物流/其他费用，已排除，不为查销量读取无关单据。其他命中只是 replenishment 详情/关联或写接口；没有自有建议记录 ID，所以没有猜 ID 继续查详情，更没有调用写接口。该结论限定于当前本地完整契约和当前服务字段目录，不推断未公开的其他版本。

getSummaryList 支持的是店铺、ASIN/MSKU 维度及列表、分页筛选；没有预测起止日、预测天数或算法选择参数。`listing_date_range` 是 Listing 创建时间筛选且当前 unsupported；`mode` 当前也标 unsupported，并注明缺少海外仓中转建议计算引擎。它们不能被当作启用未来预测的开关。REST 的 `daily_sales`、`date_from/date_to` 列在查询筛选参数中，未声明为重新计算输入或未来预测区间。本轮未传入猜测的 horizon/window/算法参数。

## 对 S01 的建议

当前保留已验证的可配置 7 完整业务日 SMA：观察窗、业务日、履约/库存对账、算法与日需求曲线都可追溯。两款现阶段没有可接入的 ERP 未来预测或源建议，**不值得据此替换现有输入，不调整当前 45 EA 候选，也不需要重构 B02**。

若老师后续确认真实预测能力，应先取得两款 SKU 的非空样本、预测起止日/粒度、观察口径、算法或维护来源、版本/更新时间、单位与断货处理，再将其作为可选的 D01/D02 需求来源，与 SMA 并列比较。来源为单个预测日均时，延伸逐日曲线仍需明确假设；来源若是采购建议，只作对照结果。B02 继续负责构造候选和采购约束并调用 B01 评价，不因 ERP 返回一个建议数就跳过自身计算/质量校验。
